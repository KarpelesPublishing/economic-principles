# Chapter 71: Bureaucracy, Public Choice, and Budget Politics

Test package deals, expected rescues, voter information and shared budgets by comparing who gains with who pays.

Notebook with the worked examples and figures: `../../notebooks/ch071-bureaucracy-public-choice-and-budget-politics.ipynb`

## 1. Logrolling (logrolling)

When to use it: a vote trade that passes projects each failing alone.

    Delta V_A=7-2=5;  Delta W=5+5-4=6

Steps: host net b - t per project (book: 9 - 2 = 7); trader gain (b - t) - t (book: 5); outsider -2t (book: -4); total 2(b - 2t) - 2t (book: 6; with tax 4: 1 + 1 - 8 = -6).

Watch for: traders gaining is not proof that the council gains.

## 2. Soft budget constraint (soft-budget-constraint)

When to use it: an organization expects support after losses.

    0.5(180-140)+0.5(80-140)=-10;  0.5(40)+0.5(-10)=15

Steps: true expected value of the risky plan (book: -10); perceived value with the bailout in the loss state (book: 15); compare with the safe plan (book: 10, so the large plan is chosen); exposure p x bailout (book: 25).

Watch for: a tie with the safe plan should be reported as indifference.

## 3. Rational ignorance (rational-ignorance)

When to use it: is it worth becoming informed before a vote?

    c=3 x $18=$54;  pB=(1/200,000) x $600=$0.003

Steps: cost c (book: 54); expected benefit pB + d (book: 0.003); net (book: -53.997, stay uninformed; committee p = 0.10 gives 60 - 54 = 6).

Watch for: reusable private value d can justify study on its own.

## 4. Fiscal common-pool problem (fiscal-common-pool-problem)

When to use it: districts share the cost of locally beneficial projects.

    $6-$10=-$4 million;  (1/5) x $10=$2 million

Steps: own share cost/n (book: 2); perceived gain benefit - cost/n (book: 4, so proposed); true net benefit - cost (book: -4); if all pass, aggregate n(benefit - cost) (book: -20).

Watch for: a district-specific levy (n = 1) removes the bias.

## How to answer

- Show every substitution: write the formula, then the user's numbers in it, then the result.
- Say which inputs are the user's and which are assumptions you added.
- Name ties and undefined cases instead of forcing a winner.
- Do not present the book's hypothetical numbers as facts about any real market.
